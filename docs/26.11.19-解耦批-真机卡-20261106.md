## 1. 插拔探针（30 秒，两动作分别记录）

**这一组要看的是**：**亮着屏**的时候把线拔掉、再插回去，**各自动作之后设备会不会重启**。

**执行顺序：先拔、后插**（设备本来插着线）。记录表两格**分开填**，不写综合结论。

**怎么做（亮屏、停在书架或首页，0 号步已做）**

1. 确认屏幕**亮着**、停在书架或首页，手上准备好秒表（或手机录像对着屏幕）。
2. **拔线**。盯屏幕 **≥30 秒**：黑了？花屏？开机 logo？有没有重启？
   顺手记拔线后充电小闪电**消失**用了几秒。
3. **插回线**。再盯屏幕 **≥30 秒**：有没有开机 logo、有没有重启？
   顺手记插线后充电小闪电**出现**用了几秒。
4. 两个动作各自独立记一行：「有没有重启」「几秒」。

### B2（只在 B1 拿不到读数时兜底）：看 10 分钟里电量涨不涨

> 触发条件很窄：**插线侧安全**、但 B1 两轮都拿不到可读的闪电跳变。

**怎么做**

1. 插线，停在首页，屏幕亮着（**0 号步已做，否则 10 分钟内自动锁屏会把观测窗杀掉**）。
2. **手离开设备**，什么都不按。
3. 每 30 秒拍一张照，**拍满 10 张**（5 分钟）；若 10 张数字完全一样，再拍 10 张（共 10 分钟）。

**判**

| 你看到的 | 判定 |
|---|---|
| 数字往上走了（哪怕只 +1%） | **K1 成立，通过** |
| 10 分钟里一次都没动 | **不可判**——不记 FAIL，也不记 PASS |

## A 组：解锁第一帧（本批最重要的一组）

**前提两条**：B 组至少看到过一次成立（B1 两轮都过 / B2 看到上涨）；**并且这一组要用电池跑，不插线**。

**为什么要拔线**：插着线时电量百分比可能被 C② 冻住，这时「第一帧旧值、之后一直不变」既可能是本批的 P1，也可能只是电量压根没动——**变量混在一起，对照就废了**。
前一版基线（W1）就是纯电池跑的，**这一组必须与它同态**：纯电池、不连 USB、同样的锁屏时长档。

**代价**：拔线后**没有串口日志**，这一组只能靠**手机录像**判读——这是已知代价，不是疏漏。

### 开跑前先读：这一组会长什么样（三句预写）

1. **预期落点就是「全同」。** 纯电池、锁屏 3 分钟，电量静置几乎必不动（前基线 86 秒不掉 1%）。
   全同恰好命中不可判注里的两枚良性机制。**这不是判据失败，是电量静止下的信息论天花板**——
   真实值不变时，「停旧值且不更新」在画面上根本不可观测。别把全同记成「A 组白跑」，也别记成「P1 已排除」。
2. **A 组的真实价值是「同态对照一致性」**：全同与前基线 10/10 同形态，就是「解耦不改用户可感行为」的直接证据。
   **P1 的实证排除不由 A 组承担**——主力在宿主 K 组（回前台 `bus_due` 必为真 ⇒ 采样必执行，逻辑层排除）
   与 B 组插线态（值链活性证据）。**别拿 A 组的全同去扛一个它扛不动的结论。**
3. **A 组保留一条异常捕获**：**状态栏时钟在走、而电量长期停，并且电量存在变化理由**时，
   那才是 P1 特征的现场形态——时钟跳变替代电量跳变，充当「主循环还活着」的代理。
   看到这一条，记 FAIL 并把录像交回。

**怎么做**

1. **拔线**（亮屏时拔；探针已按动作分别记过，按那一格判断能不能继续）。此时设备走电池。
2. 进首页，**手机架好，开始录像**，让屏幕和状态栏都进画面。
3. 记下当前电量（录像里能看清就行，记为「锁屏前」）。
4. 点按电源键 → 锁屏。
5. **等 3 分钟**（手机计时，别估）。1 分钟常常跨不过 1% 的台阶。
6. 点按电源键 → 亮屏。**录像继续拍 10 秒**再停。
7. 回放录像，用暂停/慢放逐帧看**亮起后的头几帧**。

**怎么看**

| 你看到的 | 判定 | 处置 |
|---|---|---|
| 第一帧是旧值，随后 1 秒内变成新值 | **P2** | **设计内预期，通过**。不是 bug |
| 第一帧是旧值，10 秒内**一直不变**，且时钟在走、电量有变化理由 | **P1** | **缺陷，记 FAIL** |
| 第一帧就已经是新值 | 正常 | 通过 |
| 从头到尾数字**完全一样**（**预期落点**） | **不可判** | **不记白跑、不记 P1 已排除**；记下形态，作为同态对照一致性的证据 |

> **P2 为什么不算 FAIL**：这一批把采样从「按键时顺手做」改成「主循环每 200 ms 自己做」。
> 解锁那一瞬间还没到下一个 200 ms 的点，第一帧先显示旧值，一拍之后才跟上。
> **不写清楚，现场一定有人拿 P2 报 FAIL。**
>
> **「完全一样」为什么不可判——两枚良性机制都要数到**：
> ① **漂移 = 0**：这 3 分钟电池真的没跨过 1% 台阶；
> ② **采样先于首画**：解锁后第一个主循环 tick 如果「先补采样、再整页重绘」，首帧本来就是新值——电量若也没变，画面与①完全一样。
> **这两种 tick 内顺序都合规，从来没有钉过。** 所以卡上只记「观测到的形态」，不预设必须出现 P2。

| 轮次 | 锁屏前 | 第一帧 | 10 秒后 | 时钟在走？ | 观测形态 | 判定 |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

跑 3 轮。**出现 1 次 P1 就是 FAIL**；3 轮 P2 或正常 = 通过；3 轮全「不可判」= **同态一致，照常交回**（见预写第 2 句）。

**做完记得插回线**，再做 C 组。

## C 组：PIN 界面能不能退出来（K6.1，本批的生存条件）

**怎么做**

1. 设置里打开 PIN。
2. 点按电源键锁屏 → 屏幕出现 PIN 输入界面。
3. **30 秒内点按电源键**。
4. 看能不能退回原来的页面。
5. 退出后**看日志最后几行**，应当有一行 `pmu: KEY_SHORT ...`。

**判**

| 结果 | 判定 |
|---|---|
| 退回去了，且日志里出现 `KEY_SHORT` 行 | 通过 |
| 按了没反应，卡在 PIN 界面 | **FAIL**（`take` 不自足则整条链断，这是本批的生存条件） |
| 退回去了，但日志里**没有** `KEY_SHORT` 行 | **FAIL**（退出是别的路径兜的，取键链没走通） |

> **为什么盯这一行**：本批把取键动作瘦身成「数一数、看一眼、回执一条」，断一环就不再吐 `KEY_SHORT`。
> 这一行在出货的旧包里稳定存在（`strings` 命中的就是它），**它在，说明取键链活着**。

| 这一节观测时，**有没有接着串口**（能不能导出日志） | |
| 观测期间设备**一直插着线 / 一直纯电池 / 两者都做了** | |

> 注意：**出货 bin 不打触摸/导航事件日志**（日志里只有 `pmu` 电源键行），所以「接着串口」也不等于
> 「日志能看见这次动作」。这一节靠**肉眼 + 手机录像**记，日志能导就一并附上（有没有都交回）。

**两态都记、并排对照**：A 组（纯电池）与 B 组（插线）窗口都按同一张表记，比一比有没有、几次、间隔。
**不新增组、不额外跑一轮。** 插线明显更高发 ⇒ 供电是调制因素；两态一样 ⇒ 源与供电无关。

### 一个判别动作（下次真再出现时，顺手做一下）

**退出之后完全不碰屏，静置 ≥30 秒**，看它自己进不进书：

- **自己进** ⇒ 触发不依赖用户动作，像「持续鬼点源」；
- **不进、必须再点一下退出才进** ⇒ 与「退出 / 回首页」动作耦合，像「状态残留」。

再用手机录像**数一数「退出 → 再进」隔了几秒**（固定周期 / 贴合退出即时 / 连发几次后停，三种形态别替它归类，只记数）。
上次说的「马上又进去」是定性词、没量化；这一格是分辨原因最值钱的一列。

### A 组窗口被干扰时怎么办

A 组要逐帧看「亮起后头几帧电量」。**如果鬼点在 A 组窗口复发（画面自己进书了），那一轮没法判**：
**先按本节把现象记下来，A 组该轮记「受干扰 · 不可判」，另补一轮**；
**别把「画面自己进书」误读成 P1/P2 的某种形态**——那是另一类现象，不是解锁第一帧。

## 交回什么

1. 这张卡（各组表填满；**0 号步原档位、探针两行记录**必填，两行不合并；**E 节表若有非预期动作也一并交回**）。
2. 全程串口日志（一个文件，别截断；A 组那段没有日志是正常的，注明起止时刻）。
3. A 组的录像（3 轮各一段）。
4. **E 节单列**：非预期行为记录表（哪怕一格没发生，也写「全程无非预期动作」——空的也是信息），
   **本轮** E 节那两格（插线态 / 串口态，**别拿上次现象的答案填**），以及当时刷的 bin 版本串或
   `readback.sh` 结果（用来钉死是哪颗包：**`0.3.9-pico26.11.18` = 旧包 / `0.3.9-pico26.11.19` = 新包**）。
   > 上次现象固定表已于 19:22 回填（纯电池 / 没连电脑 / 关自动息屏 / 首页 / 约 5–6 次 / 关机才停）；
   > **bin 版本串那一格仍空**，这一项就是要补上它。

**判定汇总**：探针两格有结论 + B 组成立 + A 组 3 轮全过或同态全同 + C 组 2 次全过 + D 组无差异 = **本批真机 PASS**。
任一组 FAIL，把卡和日志一起交回，**不要自行重刷**。落在「不可判」也要交回——**不可判不是失败，是信息**。

> **E 节不进这条汇总**。它是另一个账（C③）的观察材料，采到什么都不改本批 PASS/FAIL，也不改 PENDING。
