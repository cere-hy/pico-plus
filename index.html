怎么用 · 三步
  1. 电脑上插入 TF 卡（或读卡器），在卡盘最上层建一个 dict 文件夹。

01 / GESTURES

手势与框选

这台设备不只是翻页：首页、阅读页各有双指手势，正文还能框选一段存成摘抄。

FEATURE 01 · 首页

首页双指 / 空白长按

在首页用双指上滑，直接打开最新一条推送内容；在卡片与状态栏之外的空白处长按，进入传书页。

双指上滑 → 最新推送
空白长按 → 传书页
状态栏信息带不做手势领地，持机误触不会误开；单指点击、翻页等旧手势照常。
FEATURE 02 · 阅读页

阅读页双指

阅读正文时两指一起滑动：上下滑按档位调字号（下滑加大、上滑减小），横向滑切换横屏／竖屏。

双指纵向滑 → 字号 ±档
双指横向滑 → 横竖屏切换
滑动太慢或位移太小会被当成按住／抖动，不会误触；框选状态下双指滑动只用于退出框选。
FEATURE 03 · 框选

框选与存摘抄

阅读页单栏横排下，两次点按即可框出一段文字：先点首字，再点尾字，选中后底部出现动作栏。

点首字 → 再点尾字
存摘抄 / 取消
摘抄可在书架「生词本／摘抄」里回看；点选区外或按键即退出框选。
FEATURE 03 · 框选 / 真机实拍

框选，就在正文上

画面是设备竖屏单栏下的阅读页：英文正文占满屏幕，顶部浮出一排圆形快捷图标，正文中有一段被虚线框标出，右侧一支橙色箭头指向顶部图标。框选与取词就发生在这样的正文里。

两次点按选段、选中后的动作栏与回看位置，见上方 FEATURE 03 的说明；此处只放设备实拍，不重复步骤。

03 / HOW TO FLASH

刷机操作步骤

首次刷机必须连电脑：本固件分区布局与官方不同，需要整片写入。

用 USB 数据线把设备连到电脑（部分充电线只能充电，不能传数据）。
确保设备电量充足，建议 50% 以上。
点本页上方 「安装固件」 按钮。
弹窗中选择设备串口（如 COM3、USB JTAG/serial debug unit），点连接。
等待进度条走完（约 1～2 分钟），设备自动重启，刷机完成。
刷完后回到本页顶部深色区，下载并安装 App 与词典文件。
浏览器要求：需电脑版 Chrome 或 Edge；暂不支持手机浏览器和 Safari。首次刷过官方固件的设备，工具会提示「擦除全部数据」，属正常现象——两套分区布局不同，必须整片擦除后才能写入，确认即可。按钮没反应或找不到串口，换一根数据线、换一个 USB 口，并关掉其他可能占用串口的软件；页面一直转圈是刷机脚本没加载出来，换个网络环境重试。

05 / DETAILS

详细使用说明

上方两张卡是速览；这里是把每一步讲清楚的完整版。

手机端配套 App（v1.6.5）

刷完固件后，若要使用蓝牙推流、AI 智能释义、语音朗读，请在手机装配套安卓 App：下载 ReadPicoPush.apk（也可到仓库 apk/ 目录或本版 Release 附件）。

  • 仅支持 Android；iOS 因系统限制暂不支持。
  • 固件与 App 必须同时更新：旧版 App 在有多台设备并存时可能连到非目标设备。
  • Android 10/11：需打开「定位服务」总开关并授予位置权限，否则蓝牙扫描返回不了设备（App 顶部会有红／绿横幅提示）。
  • 装好后点 「连接并监听点词」 保持连接（手机前台服务保活）——这是 AI 释义和听书的前提，断开后两者即停。
  • 首次使用 AI 释义 前，在「AI 释义设置」（默认 DeepSeek）填入 API key；base_url / model / 提示词模板均可改。
  • 听书无需额外配置：设备侧打开「听书 → 跟随朗读」，手机连接后自动朗读当前页。

手机蓝牙推流怎么用

  1. 设备进入「手机推送」入口开启接收，屏幕显示广播名（如 PicoPush-1A2B）。
  2. 安卓手机打开配套 App，扫描到设备后点选连接；多台并存时按列表点选，不会推错。
  3. 在 App 里输入／粘贴要推送的文本（也支持单词卡），发送；有新推送未打开时首页状态条会出现「有新内容」。

AI 智能释义怎么用

  1. 阅读页选中单词，词典卡上点 「AI」 让手机调用大模型给出详解；点 「看全文 ›」 进详解阅读视图。
  2. 释义走蓝牙：设备发查询 → 手机 App 调模型 → 回传结果显示在设备。查询中显示「AI 查询中…」，超时会自动回退到离线词典释义。
  3. 需手机已点「连接并监听点词」保持连接，并已填入 API key。
  4. 设备侧 AI 释义开关默认开启（设置持久保存）；整页查询无反应时，先确认手机已连接并已填 key。

语音朗读（听书）怎么用

  1. 设备「听书」里打开 跟随朗读，每翻一页自动把当前页文字经蓝牙推到手机，由手机本地中文 TTS 朗读。
  2. 息屏、锁屏都不中断（前台服务保活）；点「停止朗读」或关掉听书开关立即停止。
  3. 约 10 分钟不翻页会自动停止以省电；点词发音走同一朗读引擎，即插即播。

离线词典设置（不设置就无法查词）

本固件不包含词典数据。查词功能依赖放在 TF 卡里的词典文件，必须按下面步骤放置，否则无法使用查词功能（AI 释义不受影响，但离线释义与离线生词本需要词典文件）。
  1. 下载词典文件（二选一，推荐第一个）：
    dict.bin —— 约 8.9 MB，12.4 万词，SHA-256 2bb228e4…9ee7；
    dict-full.bin —— 约 23 MB，40 万词，SHA-256 7c17cca7…f61b。
  2. 如果下载的是 dict-full.bin，先把它重命名为 dict.bin。
  3. 把 dict.bin 复制到 TF 卡根目录下的 dict 文件夹：电脑上插入 TF 卡，打开卡盘，在最上层建一个名为 dict 的文件夹，把文件放进去——放好后卡里就是 dict/dict.bin 这一层结构。没有 dict 文件夹就新建一个（设备插卡启动后也会自动创建）。
  4. TF 卡插回设备并重启，之后阅读时选中单词即可查词，查过的词自动进生词本。

命名与位置必须严格一致：文件叫 dict.bin，放在 TF 卡根目录的 dict 文件夹下。文档里的设备内部路径 /sdcard/dict/dict.bin 中，/sdcard 只是固件里 TF 卡的挂载点名（卡插到电脑上，看到的就是卡盘根目录本身），不是让你在卡上再建一层 sdcard 文件夹；其他名字、其他位置都不生效。dict 文件夹里只放一个词典文件，放多个时打开哪一个不确定。词典数据由 ECDICT（MIT）转换生成，也可用仓库里的 tools/build_dict.py 自行构建。

常见问题

  • 按钮点了没反应／找不到串口？换数据线、换 USB 口，关掉其他占用串口的软件。
  • 页面一直转圈或按钮不出现？刷机脚本没加载出来，换网络环境重试（需 Chrome / Edge 电脑版）。
  • 烧到一半失败？重新插拔 USB 后重试；反复失败可换数据线或 USB 口。
  • 刷完为什么查不了词？词典文件没放，按 STEP 02 把 dict.bin 放进 TF 卡根目录的 dict 文件夹。
  • AI 释义点了没反应？确认手机 App 已点「连接并监听点词」保持连接，且已填 API key。
  • 听书不读／突然停了？确认设备已开「听书 → 跟随朗读」且手机 App 已连接保活；断开蓝牙会立即停止。
  • 刷完想升级／重刷？可再次使用本页；也可以把 Read_Pico.bin 重命名为 Pico-update.bin 放到 TF 卡根目录，在「设置 → 升级和恢复」中安装（相同版本会被设备拒绝重装，此时请用本页重刷）。
