## 二、真机证据（本包的验收记录）

三步复测（对象即本 bin）**PASS**，判定分账：

- **数据子句（日志出证）**：①摘 129/129 字 truncated=0，卡离线中入队 pending=1，重试链走完队列不丢；②插回 364 ms 挂载 → ~5 s 冲账 flushed pending=0，7 次失败重试横跨 ~10 s 零丢失；③横屏场 tap x=846 超竖屏坐标域（旋转旁证），202/202 字 truncated=0。
- **视觉子句（目视出证）**：气泡「已入队 · 待落盘 N」2 s 消失（竖/横屏）、插回「已存 ✓」出现——固件不记 notice 事件，串口对气泡盲，视觉子句由用户眼睛出证。
- **计划外加压**：第三轮拔卡落在第二轮挂载后 ~1 s 且摘抄仍在队——队列横跨两次 media-lost，零丢失零重复。
- **健康账**：largest-free 11776 持稳、dma floor 68 B、bootbb notes 15→30 单调无泄漏形态；0x107 共 3 条全物理瞬间单发（对照旧版 83 条刷屏）。

**随批勘误（已入台账）**：冲账延迟实为插回后 **~5 s**（确定性定时器，非 ~0.5 s）；0x107 计 3 条、拔插 3 轮闭环。

## 三、功能边界（用户会看到什么）

| 场景 | 本版行为 |
|---|---|
| 阅读中拔卡 | 不闪退、不弹书架，页内提示「TF 卡已移除 · 待落盘 N」气泡化呈现；摘抄可继续入队 |
| 插回卡 | 就地重开书源留在原书原页；~5 s 后自动冲账并亮「已存 ✓」 |
| 摘抄无卡 | 入队即顶部气泡「已入队 · 待落盘 N」2 s 自动消失（横屏同），队列跨拔插零丢失 |
| 边看书边推流 | 停在原书原页，提交段四拍封送（26.9.30 语义不变） |
| 第三方占着 FILE* 拔插 | 冻结 + 10 s 逐拍重试，句柄关或重启才终态（安全降级，非死锁） |
