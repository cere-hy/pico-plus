Pico-Plus 墨水屏极客副屏固件 · 网页刷机

适用硬件：MindReset RDP-G01-W 墨水屏阅读器（ESP32-S3）

本固件为第三方修改版，基于 kiikoread r95 版（0.3.3-rc95）改造，与 MindReset 官方无关。

主要功能：

  • 双栏排版：横屏一页两栏，翻页次数减半；
  • 离线词典与生词本：阅读中点词查义、生词收藏，词典文件需自备（见下方）；
  • AI 智能释义：点词经手机调用大模型给出详解，需自备 API key；
  • 语音朗读（听书）：翻页自动把当前页推到手机朗读，息屏不中断；
  • 蓝牙推流：安卓手机把长文与单词卡推到设备，当极客副屏；
  • 网页刷机：浏览器一键烧录，无需安装任何电脑软件。

一键刷机

用 USB 数据线连接设备后，点击下面的按钮开始。

如果之前刷过官方固件，工具会提示擦除全部数据——这属于正常现象 （官方固件与本固件的分区布局不同，必须整片擦除后才能写入），确认即可。
刷机脚本没能加载出来（网络原因）。请更换网络环境后刷新本页重试； 脚本来自 jsdelivr / unpkg 两个公共 CDN。

操作步骤

  1. 用 USB 数据线把设备连接到电脑（部分充电线只能充电，不能传数据）；
  2. 确保设备电量充足（建议 50% 以上）；
  3. 点击上方 「安装固件」 按钮；
  4. 在弹窗中选择设备对应的串口（如 COM3、USB JTAG/serial debug unit），点击连接；
  5. 等待进度条走完（约 1～2 分钟），设备自动重启，刷机完成。

刷机与后续使用需电脑版 Chrome 或 Edge 浏览器；暂不支持手机浏览器和 Safari。

手机端配套 App（蓝牙推流 / AI 释义 / 听书用）· 仅安卓

若要用到蓝牙推流、AI 智能释义、语音朗读，请先在手机装配套安卓 App： ReadPicoPush.apk （也可到仓库 apk/ 目录或本版 Release 附件下载）。

  • 仅支持 Android（安卓）；不支持苹果 iOS（系统限制）。
  • Android 10/11 手机：需在系统设置里打开「定位服务」并授予位置权限，否则扫描不到设备（App 顶部会有红字提示）。
  • 固件与 App 必须同时更新：旧版 App 在有多台设备并存时可能连到非目标设备。
  • 装好 App 后，点 「连接并监听点词」 与设备保持连接（手机前台服务保活）——这一步是 AI 释义和听书的前提，断开后两者即停。
  • 首次使用 AI 释义 前，在 App「AI 释义设置」（默认 DeepSeek）里填入你的 API key；base_url / model / 提示词模板均可改，不填 key 时 App 会提示。
  • 听书无需额外配置：设备侧打开「听书 → 跟随朗读」即可，手机连接后自动朗读当前页。

AI 智能释义怎么用

  1. 在阅读页选中单词，词典卡上点 「AI」 即可让手机调用大模型给出详细释义；词卡上点 「看全文 ›」 可进入详解阅读视图。
  2. 释义走蓝牙传输：设备发查询（0x17）→ 手机 App 调大模型 → 回传结果（0x07/0x08）显示在设备。查询中会显示「AI 查询中…」，若超时未回会自动回退到离线词典释义。
  3. 需先在 App 点 「连接并监听点词」 保持连接；否则设备发出的点词查询手机收不到。
  4. 首次使用在 App「AI 释义设置」填入 API key（默认 DeepSeek，任何 OpenAI 兼容端点均可，如通义千问），可选改 base_url / model 与提示词模板。
  5. 设备侧 AI 释义开关默认开启（设置持久保存），如整页查询无反应，先在手机确认已连接并已填 key。

语音朗读（听书）怎么用

  1. 在设备「听书」里打开 跟随朗读 后，每翻一页会自动把当前页文字经蓝牙（0x19）推到手机，由手机本地朗读（中文 TTS）。翻页即续读，不排队。
  2. 息屏、锁屏都不会中断朗读（手机前台服务保活）；在 App 点 「停止朗读」 或在设备关掉听书开关会立即停止。
  3. 长时间（约 10 分钟）不翻页会自动停止朗读以省电；当前页若仍在读不会被打断。
  4. 点词发音也走同一朗读引擎，即插即播。
  5. 需要手机 App 已连接并开着「连接并监听点词」。

刷完之后必做：放置离线词典

本固件不包含词典数据。查词功能依赖放在 TF 卡里的词典文件， 不放置则无法使用查词功能（AI 释义不受影响，但离线释义与离线生词本需词典文件）。
  1. 下载词典文件 dict.bin （约 8.9 MB，推荐；需要更全词库可下载 dict-full.bin 并重命名为 dict.bin）；
  2. 把文件命名为 dict.bin，复制到 TF 卡根目录下的 dict 文件夹里： 在电脑上打开 TF 卡盘，在最上层建一个 dict 文件夹，把文件放进去 （不需要建 sdcard 文件夹——设备内路径 /sdcard/dict/dict.bin 里的 /sdcard 只是固件中 TF 卡的挂载点名， 卡插到电脑上看到的就是卡盘根目录本身）；
  3. TF 卡插回设备并重启，之后阅读时选中单词即可查词。

文件名称与位置必须严格一致：dict.bin 放在 TF 卡根目录的 dict 文件夹下，其他名字或位置不生效。详细说明见仓库 README 第四节。

常见问题

按钮点了没反应 / 找不到串口？换一根数据线、换一个 USB 口，并关掉其他可能占用串口的软件。

页面一直转圈或按钮不出现？是刷机脚本没加载出来，换个网络环境重试（需 Chrome / Edge 电脑版）。

提示浏览器不支持？必须使用电脑版 Chrome 或 Edge 浏览器；暂不支持手机浏览器和 Safari。

烧到一半失败？重新插拔 USB 后重试；反复失败可换数据线或换 USB 口。

刷完为什么查不了词？词典文件没放。本固件不包含词典数据， 需按上方「刷完之后必做」把 dict.bin 放进 TF 卡根目录的 dict 文件夹（设备内路径记为 /sdcard/dict/，无需建 sdcard 文件夹）。

AI 释义点了没反应？确认手机 App 已点「连接并监听点词」保持连接，且已在「AI 释义设置」填入 API key；设备 AI 释义开关默认开启。

听书不读 / 突然停了？确认设备已开「听书 → 跟随朗读」且手机 App 已连接保活；息屏不会中断，但断开蓝牙会立即停止（半页残留不留）。

刷完想升级/重刷？可以再次使用本页面；也可以把 Read_Pico.bin 重命名为 Pico-update.bin 放到 TF 卡根目录，在设备上「设置 → 升级和恢复」中安装 （注意：相同版本会被设备拒绝重装，此时请用本页面重刷）。
